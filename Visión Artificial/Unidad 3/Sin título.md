
| ==🔵==                | OpenCV                                                                                                                              | Sci-Kit                                                                                                                                    | Yolo                                                                                                                       |
| :-------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| **¿Que es?**          | Una biblioteca de código abierto enfocada en visión por computadora y procesamiento de imágenes en tiempo real.                     | Un ecosistema de bibliotecas en Python para aprendizaje automático (_scikit-learn_) y procesamiento de imágenes (_scikit-image_).          | Una familia de algoritmos y modelos de aprendizaje profundo (_Deep Learning_) basados en redes neuronales convolucionales. |
| **¿Para que se uso?** | Manipulación de imágenes y video, detección de bordes, reconocimiento facial, seguimiento de objetos y calibración de cámaras.      | Clasificación, regresión, agrupamiento (_clustering_), análisis de datos (_learn_) y filtrado o segmentación básica de imágenes (_image_). | Detección, clasificación y segmentación de múltiples objetos en imágenes o video en tiempo real con alta precisión.        |
| **Ventajas**          | • Muy rápido (optimizado en C++).  <br>• Gran cantidad de funciones clásicas.  <br>• Multiplataforma y gratuito.                    | • Muy fácil de aprender y usar.  <br>• Excelente documentación.  <br>• Se integra perfecto con NumPy y Pandas.                             | • Extremadamente rápido (procesa la imagen en una sola pasada).  <br>• Alta precisión en detección en tiempo real.         |
| **Desventajas**       | • Curva de aprendizaje algo alta para funciones avanzadas.  <br>• Menos enfocado en redes neuronales modernas que otros frameworks. | • No está diseñado para _Deep Learning_ ni procesamiento de video en tiempo real.  <br>• Lento con volúmenes masivos de datos.             | • Requiere mucho poder de cómputo (GPU) para entrenar.  <br>• Menor precisión con objetos muy pequeños o muy juntos.       |
| **lenguaje**          | C++ (principal), con interfaces oficiales para **Python**, Java y MATLAB.                                                           | **Python** (con partes optimizadas en Cython y C).                                                                                         | C / C++ (versiones originales en Darknet) y **Python** (versiones modernas como Ultralytics / PyTorch).                    |
